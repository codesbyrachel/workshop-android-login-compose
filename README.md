# 📱 Workshop Android - Login com Jetpack Compose

Repositório prático para o workshop de criação de telas modernas com **Jetpack Compose** e **Material 3**.

---

## 🚀 Como Clonar o Projeto

Abra o terminal e execute:

```bash
git clone https://github.com/codesbyrachel/workshop-android-login-compose.git
cd workshop-android-login-compose
```

Em seguida, abra o projeto no **Android Studio** e aguarde a sincronização do Gradle.

---

## 🌿 Navegando entre as Branches (Desafios)

A branch `main` contém a **estrutura inicial** desenvolvida junto durante a aula. Conforme os desafios forem sendo resolvidos, você poderá navegar entre as branches usando o comando `git checkout`:

| Branch | Descrição | Comando para acessar |
| :--- | :--- | :--- |
| `main` | 🏁 **Ponto de Partida** (Código base da aula com os TODOs) | `git checkout main` |
| `desafio-1-nome` | 👤 Adiciona o campo de **Nome** (`OutlinedTextField`) | `git checkout desafio-1-nome` |
| `desafio-2-botao-convidado` | 🎟️ Adiciona o botão **Entrar como convidado** (`OutlinedButton`) | `git checkout desafio-2-botao-convidado` |
| `desafio-3-cadastrar` | 🔗 Adiciona o link **Não tem uma conta? Cadastre-se** (`TextButton`) | `git checkout desafio-3-cadastrar` |
| `desafio-plus-senha` | 🔒 **Desafio Plus**: Campo de **Senha com visualização (Olhinho)** | `git checkout desafio-plus-senha` |
| `login-final` | 🏆 **Versão Completa**: Todos os componentes e desafios combinados | `git checkout login-final` |

> 💡 **Dica:** Para voltar para a versão inicial a qualquer momento, basta rodar:
> ```bash
> git checkout main
> ```
